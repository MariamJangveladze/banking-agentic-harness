# Security and Portfolio Boundaries

## Included

- Synthetic cases, policies and documents
- Deterministic model route plus optional local Ollama/Chroma
- Human approval interrupt
- Evidence and evaluation contracts
- PostgreSQL checkpoint seam

## Excluded

- Bank credentials, customer information or confidential documents
- Real write adapters
- Payment, account, credit or onboarding execution
- Production authorization claims

## Production controls required

- Enterprise identity, roles and segregation of duties
- Policy decision point and obligation enforcement
- Encrypted secrets/data, egress controls and approved model endpoints
- Prompt-injection and retrieval-content controls
- Immutable evidence ledger and retention policy
- SIEM integration, incident response and kill switch
- Threat model and independent security testing
